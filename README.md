# Web UART - 现代化网页串口调试助手 🚀

这是一个基于浏览器原生 **Web Serial API** 开发的现代化、高颜值、全功能网页串口调试工具。它完全在浏览器本地运行，**无需安装任何驱动（除硬件本身的 USB-to-TTL 驱动外）或后台程序**。

页面采用了精美的 **暗黑玻璃拟态 (Glassmorphism)** 科技风设计，并支持响应式布局，无论在什么分辨率的屏幕上都能获得极佳的体验。

---

## ✨ 核心特性

- 🔌 **零门槛即开即用**：只需使用支持 Web Serial API 的现代浏览器打开，即可直接与物理串口设备通信。
- 🎨 **现代化视觉交互**：
  - 精心调配的 HSL 渐变暗黑主题与毛玻璃边框。
  - **RX/TX 动态信号闪烁指示灯**与物理**连接状态 LED 呼吸灯**。
  - 顺滑的数据滚动与可定制的控制开关。
- ⚙️ **完整的串口参数配置**：支持波特率（含自定义输入）、数据位、停止位、校验位、流控制（RTS/CTS），以及硬件信号控制 DTR、RTS 的手动切换。
- 📑 **强大的收发控制**：
  - 文本 (TXT) / 十六进制 (HEX) 双接收与发送模式。
  - 可独立控制的自动换行、毫秒级高精度接收时间戳、自动滚屏。
  - 支持“暂停屏幕数据更新”（此时后台数据接收依旧继续，避免遗漏关键报文）。
  - 支持无换行、`\n`、`\r`、`\r\n` 四种发送后缀。
- ⏱️ **高精度定时循环发送**：输入自定义周期（毫秒），一键开启无人值守循环自动发包。
- 💾 **本地快捷指令（Macro Presets）**：
  - 提供 8 组独立快捷指令槽位。
  - 支持随时在线修改与一键**保存至浏览器本地存储 (`localStorage`)**，页面刷新或重新打开指令不丢失。
- 📤 **一键导出运行日志**：支持将监控终端中的交互历史（附带时间戳和收发标记）一键打包下载为标准的 `.txt` 纯文本日志。

## 🖥️ 浏览器兼容性

本工具使用了 **Web Serial API**，该 API 目前被主流基于 Chromium 的现代浏览器所原生支持：
- **Google Chrome** (版本 89+) ✅
- **Microsoft Edge** (版本 89+) ✅
- **Opera** (版本 75+) ✅

*注：由于安全与隐私政策，Firefox (火狐) 与 Safari (苹果) 浏览器目前暂不支持该 API。若在不支持的浏览器中打开，工具将自动展示友好的不支持警告蒙层。*

## 🛠️ 快速启动

由于 Web Serial API 强制要求运行在 **安全上下文**（即 `localhost` 或 `HTTPS` 协议链接）中才能被浏览器允许激活使用，因此**强烈建议**通过本地网页服务器运行，而不是直接双击 HTML 文件（直接打开 file:// 协议可能会导致部分浏览器禁用 Web Serial 权限选择器）。

### 方法一：使用 Node.js (推荐)
无需全局安装，在项目根目录下直接使用 npm 运行命令：
```bash
# 启动本地服务器
npm run dev

# 或者
npm start
```
启动后在 Chrome/Edge 浏览器中访问：`http://localhost:3000`

### 方法二：使用 Python (免安装)
如果您的电脑中已安装 Python，可以在终端中进入当前目录并运行：
```bash
python3 -m http.server 3000
```
然后访问：`http://localhost:3000`

### 方法三：一键部署到云端
由于该应用完全是静态资源，您可以将这三个文件（`index.html`、`style.css`、`app.js`）放置在任何支持静态网页托管的服务中：
- GitHub Pages
- Gitee Pages
- Vercel
- Netlify


## 🔒 隐私与安全

本工具**完全在您的浏览器本地执行所有数据收发与转换**。没有任何形式的云端网络请求或后门程序，您的设备信息、通信报文以及快捷键配置绝对安全，绝不会被上传至任何服务器。
